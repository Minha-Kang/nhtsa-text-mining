# NHTSA 텍스트마이닝 및 6개월 리콜 기록 예측용 데이터

신고 텍스트 정제부터 증상 주석, 토픽·벡터 생성, 월별 모델 입력과 공식 리콜 기록 기반 목표까지 준비한 데이터입니다. 리콜 예측 모델 자체는 학습하지 않았습니다.

## 최신 모델 입력 데이터 v2

**[모델 입력 데이터 받기 — 약 2.47GB](https://github.com/Minha-Kang/nhtsa-text-mining/releases/tag/model-ready-v2-2026-09-29)**

아래 세 파일을 최신 릴리스의 Assets에서 같은 폴더에 다운로드하세요.

- `nhtsa_model_ready_v2.zip.001`
- `nhtsa_model_ready_v2.zip.002`
- `restore_zip.py`

```bash
python restore_zip.py
```

두 조각을 원래 ZIP으로 복원하면서 크기와 SHA-256을 검증합니다. 복원은 Python 표준 라이브러리만 사용합니다. 조각은 각각 독립 ZIP이 아니며 **자동 생성된 Source code (zip)에는 데이터가 없습니다.**

압축을 풀고 `MODEL_HANDOFF.md`를 읽으세요. Python 3.12에서 `requirements.txt`를 설치하고 `load_model_data.py`로 입력 X와 목표 y를 읽을 수 있습니다. 완성된 X/y 사용에는 v2 패키지만 있으면 됩니다.

| v2 결과 | 내용 |
|---|---|
| 신고별 증상 주석 | 전체 1,603,647건에 대한 23개 규칙, 근거 문구·충돌·미분류 표시 |
| 텍스트 표현 | NMF 16개 탐색 토픽, TF-IDF 30,000열, SVD 32차원 |
| 월별 입력 X | 브랜드(MAKE)·모델·연식·월 단위 6,597,714행, 특징 415개 |
| 별도 목표 y | 다음 6개 달의 공식 리콜 캠페인 접수 기록 여부 |
| 코드와 문서 | 읽기·재실행 코드, 훈련 기간에만 적합한 변환기, 인수인계·검증 결과 |

**y는 같은 브랜드·모델·연식의 공식 리콜 기록 여부입니다. 개별 신고·VIN의 실제 리콜 대상 여부나 특정 고장 원인을 확정하지 않습니다.** 증상 규칙은 전문가 정답이 아닌 약한 주석이며, 토픽 수 16은 탐색 설정입니다. 미래 기간이 부족하거나 차량명이 불확실한 목표는 NULL로 보존했습니다. 리콜·후보 연결 정보는 예측 입력에 넣으면 안 됩니다.

## 이전 원본·정제·후보 연결 자료

**[원본 보관용 v1 받기 — 약 3.69GB](https://github.com/Minha-Kang/nhtsa-text-mining/releases/tag/dataset-2026-09-28)**

원문 대조, 정제 기준 변경, 전체 재생성에 사용합니다. 공식 원본 `raw/`, 정제 데이터 `processed/`, 신고–리콜 후보 연결 `linked/`와 코드·설명서가 있습니다. v1 릴리스의 두 조각과 복원 스크립트를 별도 폴더에 다운로드해 복원하세요.

- 정제 차량 신고 1,603,647건
- 전체 후보 쌍 8,164,815쌍
- 원본 ZIP 46개 파일

**v1의 후보 연결은 해당 신고 차량이 실제 리콜됐다는 확정 정답이 아닙니다.** `odi_number`와 `CAMPNO`를 직접 연결하는 공통 신고 키가 없어 차량 조건·부품·설명문을 비교한 참고 관계입니다. 연결=1, 미연결=0으로 학습용 정답을 만들면 안 됩니다. 자세한 내용은 v1의 `HANDOFF.md`, `linked/JOINED_DATA_GUIDE.md`에 있습니다.

전체 재생성 시 `nhtsa_text_mining/`과 `nhtsa_model_ready_v2/`를 나란히 놓고 v2 README의 순서를 따르세요.

## 출처와 관측 범위

[NHTSA Datasets and APIs](https://www.nhtsa.gov/nhtsa-datasets-and-apis)의 공개 신고·리콜 자료를 사용했습니다. 원본 작업본은 2026-09-28, v2 관측 기준일은 2026-08-31입니다. 현재 스냅샷은 과거 수정사항을 포함할 수 있으며 실제 과거 공개 상태나 자료 완전성을 보장하지 않습니다.
